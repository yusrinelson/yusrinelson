# Featured Project

## Apex Coaching — Full-Stack Football Coaching Platform

A full-stack web application built to support a football coaching business with online training programmes, customer enquiries, and coaching session management.

Developed using **Vue.js, Node.js, Express.js, and MongoDB**, the platform connects a responsive frontend with a RESTful backend to deliver a structured programme enquiry and session management workflow.

### Key Features

- 🔐 **Authentication & User Profiles** — User authentication, protected routes, and profile management.
- ⚽ **Training Programmes** — Browse coaching programmes and view programme details.
- 📝 **Programme Enquiries** — Submit enquiries with player details and programme selection.
- 📲 **WhatsApp Integration** — Continue the enquiry process through pre-filled WhatsApp messages.
- 🗓️ **Enquiry & Session Management** — Backend workflows for reviewing enquiries, accepting or declining requests, and scheduling coaching sessions.
- 🔑 **REST API & Security** — Protected endpoints, JWT-based authentication, and password management.
- ☁️ **Cloud Deployment** — Frontend deployed on Vercel, backend hosted on Render, and data stored in MongoDB Atlas.
